## ✨ Features

- **Pixel-faithful layout** built directly from the Figma file
- **Fully responsive** for desktop, tablet, and mobile
- **Clean semantic HTML** with `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>`
- **CSS variables** for colors, so the theme is easy to change
- **Smooth scrolling** between sections, with reduced-motion support
- **Optimized images** (the hero photo was compressed from 6.7 MB to about 125 KB)
- **Keyboard-friendly** focus styles on links and buttons

## 🧩 Page Sections

| Section | Description |
| --- | --- |
| Navigation | Logo, menu links, and an early access button |
| Hero | Headline, short description, and two call-to-action buttons |
| Problem | Four cards explaining why notes fail without structure |
| Solution | "Your second brain" with image and feature checklist |
| Call to Action | Final sign-up prompt |
| Footer | Logo, social links, and copyright |

## 🚀 Getting Started

No build step or dependencies are needed.

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/knowledge-vault.git
   ```
2. **Open the folder**
   ```bash
   cd knowledge-vault
   ```
3. **Open `index.html`** in your browser, or use the Live Server extension in VS Code.

## 🌐 Deploy with GitHub Pages

1. Go to **Settings → Pages** in your repository.
2. Under **Source**, choose the `main` branch and the `/ (root)` folder.
3. Click **Save**. Your site will be live at `https://your-username.github.io/knowledge-vault/`.
